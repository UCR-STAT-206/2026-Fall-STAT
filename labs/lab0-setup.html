Lab 0: Setting Up Your Workspace

Published

September 25, 2026

Goals

  1. Access a virtualized computing environment as a local Docker container.
  2. Integrate your computing environment with VS Code.
  3. Configure Git for documenting your work and submitting assignments.
  4. Practice setting up software in a Unix-like environment.

The Tools

You are responsible for installing the following on your machine:

  1. Docker Desktop
  2. VS Code

Once you create a container using the class image, you will have access to:

  1. a Unix Shell (we will use zsh by default),
  2. Git,
  3. Quarto, and
  4. Julia 1.12.7.

In addition to various tools installed on the image (i.e. Unix utilities), you also have access to

  1. Python 3.14,
  2. R 4.5, and
  3. DuckDB 1.5.5.

On Your Own

1. Get the class Docker image working on your computer

Read the guide on how to use Docker in this class.

2. Practice using the terminal

Read the notes on the Unix shell and experiment inside a container.

3. Read up on Git, GitHub, the SSH protocol

Try setting up Git on your container and create your GitHub account.

  1. What is Git? and How to configure Git.
  2. How to set up your GitHub account.
  3. What is SSH?.

In Person

The following tasks involve using the class Docker image. Instructions are to be carried out inside a running container unless otherwise specified.

1. Download and install Quarto

  1. Inside your terminal, run uname -m to determine whether your container is setup with an arm64 or x86_64 architecture.

  2. Based on the result in the previous step, download Quarto using curl:

    curl -fL -o quarto.tar.gz \
https://github.com/quarto-dev/quarto-cli/releases/download/v1.10.18/quarto-1.10.18-linux-arm64.tar.gz

    or

    curl -fL -o quarto.tar.gz \
https://github.com/quarto-dev/quarto-cli/releases/download/v1.10.18/quarto-1.10.18-linux-amd64.tar.gz

  3. Next, unpack files from the tarball into /home/student/.local:

    tar -xvzf quarto.tar.gz --strip-components=1 -C ~/.local

  4. Finally, check that Quarto can be run from your terminal (and therefore seen by other programs) with

    quarto check

2. Let us know your GitHub username

Fill out the Google form to record the username you wish to use for this course. It will be used to set up your private repository for this class.

3. Fill out the class survey

See this Google form to answer a few questions. It will help the instructors understand everyone’s background.

4. Practice creating your first Quarto document

See the notes on Quarto and explore Quarto’s features.
