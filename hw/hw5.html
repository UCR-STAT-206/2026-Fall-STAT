Background

This assignment will guide you through the implementation of PageRank using the numerical methods we’ve learned so far. Let’s refresh our memory of the problem description:

Let \(\mathbf{A} \in \{0,1\}^{n \times n}\) represent the connectivity matrix of \(n\) web pages with entries

\[ a_{ij} = \begin{cases} 1, & \text{if page $i$ links to page $j$} \\ 0, & \text{otherwise} \end{cases}. \]

Remember that \(\mathbf{A}\) is not necessarily symmetric so we define \(r_{i} = \sum_{j} a_{ij}\) as the out-degree of page \(i\), reflecting the number of outgoing links. Imagine a random (web) surfer exploring the space of \(n\) pages according to the following rules:

  • From page \(i\) with \(r_{i} > 0\):
    • With probability \(p\) they randomly choose a random link on a page \(i\) (uniformly) and follows from that link to the next page.
    • WIth probability \(1-p\) they randomly choose one page from the set of all \(n\) pages (uniformly) and proceeds to that page.
  • From a page \(i\) with \(r_{i} = 0\) (a dangling page), they randomly choose one page from the set of \(n\) pages (uniformly), thus avoiding getting stuck at a page without outgoing links.

We will refer to \(p\) as the teleportation parameter, such that higher values correspond to the surfer following links and lower values allowing for more teleportation. Put together, the description above defines a Markov chain governed by its transition matrix \(\mathbf{P}\).

According to standard Markov chain theory, the (random) position of the surfer converges to the stationary distribution \(\mathbf{x} = (x_{1}, \ldots x_{n})^{\top}\) of the Markov chain. Each component \(x_{i}\) has the natural interpretation of the proportion of times the surfer visits page in the long run. Therefore \(\mathbf{x}\) serves as a ranking of pages: a higher \(x_{i}\) means page \(i\) is visited often. It is well-known that \(\mathbf{x}\) is the left eigenvector corresponding to the top eigenvalue 1 of the transition matrix \(\mathbf{P}\). That is, \[ \mathbf{P}\mathbf{x} = \mathbf{x}. \] This equation can be solved as an eigen-problem. It can also be cast as solving a linear system of equations, namely \((\mathbf{I}_{n} - \mathbf{P}^{\top})\mathbf{x} = \mathbf{0}\) subject to the linear equality constraint \(\sum_{i=1}^{n} x_{i} = 1\), ensuring \(\mathbf{x}\) represents a probability vector. We can view this as the extended system \[ \begin{bmatrix} \mathbf{I}_{n} - \mathbf{P}^{\top} \\ \mathbf{1}_{n}^{\top} \end{bmatrix} \mathbf{x} = \begin{bmatrix} \mathbf{0}_{n} \\ 1 \end{bmatrix}, \] which has full column rank (the original equation is rank deficient due to the fact that \(\mathbf{P}\mathbf{1} = \mathbf{1}\)). The insight we gain from this analysis is that, for an iterative solver, we can seed the initial guess with a vector with all positive entries to guarantee we recover a valid solution to the PageRank problem without directly enforcing \(\sum_{i=1}^{n} x_{i} = 1\). Farkas’ Lemma applies here.

Problem 2: Understanding the Transition Matirx \(\mathbf{P}\)

Let \(X_{k} \in \{1,2,\ldots,n\}\) denote the page visited by the surfer after \(k\) steps. Also denote by \(Z\) whether the surfer teleports or not (\(Z^{c}\)). Given the past history, the page next visisted by the surfer is roughly described by the law of total probability and the Markov property, namely that \[ \Pr(X_{k+1} = j \mid X_{k} = i) = \Pr(X_{k} = i \mid Z)\Pr(Z) + \Pr(X_{k} = i \mid Z^{c})\Pr(Z^{c}). \] The left-hand side is precisely \(P_{ij}\); that is, a one-step transition probability and it is the same regardless of \(k \ge 0\).

Use the relation above to enumerate all possible entries in \(P_{ij}\) in terms of web page connectivities, \(A_{ij}\), out-degrees \(r_{i}\), and teleportation parameter \(p\).
