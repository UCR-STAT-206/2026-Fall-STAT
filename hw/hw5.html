Background

This assignment will guide you through the implementation of PageRank using the numerical methods we’ve learned so far. Let’s refresh our memory of the problem description:

Let \(\mathbf{A} \in \{0,1\}^{n \times n}\) represent the connectivity matrix of \(n\) web pages with entries

\[ a_{ij} = \begin{cases} 1, & \text{if page $i$ links to page $j$} \\ 0, & \text{otherwise} \end{cases} \]

Remember that \(\mathbf{A}\) is not necessarily symmetric so we define \(r_{i} = \sum_{j} a_{ij}\) as the out-degree of page \(j\), reflecting the number of outgoing links from page \(i\). Imagine a random (web) surfer exploring the space of \(n\) pages according to the following rules:

  • From page \(i\) with \(r_{i} > 0\):
    • With probability \(1-p\) they choose a link on a page \(i\) uniformly at random and follow that link to the next page.
    • With probability \(p\) they choose one page from the set of all \(n\) pages uniformly at random and proceed to that page.
  • From page \(i\) with \(r_{i} = 0\) (a dangling page), they randomly choose one page from the set of \(n\) pages uniformly at random, thus avoiding getting stuck at a page without outgoing links.

We will refer to \(p\) as the teleportation parameter, such that higher values correspond to the surfer following links and lower values allowing for more teleportation. Put together, the description above defines a Markov chain governed by its transition matrix \(\mathbf{P}\).

According to standard Markov chain theory, the (random) position of the surfer converges to the stationary distribution \(\mathbf{x} = (x_{1}, \ldots x_{n})^{\top}\) of the Markov chain. Each component \(x_{i}\) has the natural interpretation of the proportion of times the surfer visits page \(i\) in the long run. Therefore, \(\mathbf{x}\) serves as a ranking of pages: a higher \(x_{i}\) means page \(i\) is visited often. It is well-known that \(\mathbf{x}^{\top}\) is the left eigenvector corresponding to the top eigenvalue 1 of the transition matrix \(\mathbf{P}\). That is, \[ \mathbf{x}^{\top} \mathbf{P} = \mathbf{x}^{\top} \quad \text{or equivalently} \quad \mathbf{P}^{\top}\mathbf{x} = \mathbf{x}. \] This equation can be solved as an eigen-problem. It can also be cast as solving a linear system of equations, namely \((\mathbf{I}_{n} - \mathbf{P}^{\top})\mathbf{x} = \mathbf{0}\) subject to the linear equality constraint \(\sum_{i=1}^{n} x_{i} = 1\), ensuring \(\mathbf{x}\) represents a probability vector. We can view this as the extended system \[ \begin{bmatrix} \mathbf{I}_{n} - \mathbf{P}^{\top} \\ \mathbf{1}_{n}^{\top} \end{bmatrix} \mathbf{x} = \begin{bmatrix} \mathbf{0}_{n} \\ 1 \end{bmatrix}, \] which has full column rank (the original system \(\mathbf{I}_{n} - \mathbf{P}^{\top}\) is rank deficient due to the row-stochastic property \(\mathbf{P} \mathbf{1}_{n} = \mathbf{1}_{n}\)). The insight we gain from this analysis is that, for an iterative solver, we can seed the initial guess with a vector with all positive entries to guarantee we recover a valid solution to the PageRank problem without directly enforcing \(\sum_{i=1}^{n} x_{i} = 1\). The Perron-Frobenius Theorem guarantees existence and uniqueness here.

Problem 2: Understanding the Transition Matirx \(\mathbf{P}\)

Let \(X_{k} \in \{1,2,\ldots,n\}\) denote the page visited by the surfer after \(k\) steps. Let \(Z\) denote the event that the surfer teleports (with probability \(\Pr(Z) = p\)), and \(Z^{c}\) denote the event that the surfer follows a link (with probability \(\Pr(Z^{c}) = 1-p\)).

By the Law of Total Probability and the Markov property, the one-step transition probability from page \(j\) to page \(i\), which we represent with notation \(P_{ij} = \Pr(X_{k+1}=i \mid X_{k} = j)\), is given by \[ P_{ij} = \Pr(X_{k+1} = j \mid X_{k} = i, Z)\Pr(Z) + \Pr(X_{k+1} = j \mid X_{k}=i,Z^{c})\Pr(Z^{c}). \] These one-step probabilities only depend on the previous state, \(X_{k} = i\).

Use the relation above to enumerate all possible entries \(P_{ij}\) in terms of web page connectivities, \(a_{ij}\), out-degrees \(r_{j}\), total pages \(n\), and teleportation parameter \(p\).

Problem 4: Fast Matrix-Vector Products

We’d like to leverage the existing software like KrylovKit to solve the PageRank problem. Such tools expect us to provide a Matrix-like object for matrix-vector products. Unfortunately, we cannot do this directly because \(\mathbf{M} = \mathbf{I}_{n} - \mathbf{P}\) is dense. To maximize performance, we need to exploit the structure of \(\mathbf{P}\) by implementing fast matrix-vector products using a wrapper type.

A. A Custom Matrix Type

Below it is a constructor that tells Julia how to build an instance of PageRankImP given a particular set of imputs. B. Polymorphism in Julia

The object above is useless by itself. The next three lines of code define methods for existing functions in the language specific to our type. These definitions give our object new behaviors; hence polymorphism.

import Base: getindex, size
import LinearAlgebra: issymmetric, mul!

# matrix element access M[i, j]
Base.getindex(M::PageRankImP, i, j) = (i == j) - M.d[i] * M.A[i, j] - M.v[j]
LinearAlgebra.issymmetric(M::PageRankImP) = issymmetric(M.A)
Base.size(M::PageRankImP) = size(M.A)

A. Solving the linear system

GMRES solves linear systems without assuming symmetry or positive/negative definiteness.

# normalize in-degrees to be the start point
x0   = vec(sum(A, dims = 1)) .+ 1.0
x0 ./= sum(x0)

# right hand side
b = zeros(n)

# warm up (compilation)
linsolve(transpose(M), b, x0,
  issymmetric = false,
  isposdef = false,
  maxiter = 1)

# output is complex eigenvalue/eigenvector
(x_gmres, info), time_gmres, = @timed linsolve(transpose(M), b, x0, issymmetric = false, isposdef = false, maxiter = size(M, 2))
