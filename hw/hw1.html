Problem 2

Let’s check whether floating point numbers obey certain algebraic rules.

  • If you believe a rule does not hold, provide one counterexample violating the rule.
  • If you believe a rule does hold, give a brief explanation of why it must always be true.

Associative Addition

The associative rule for addition states that \((x + y) + z = x + (y + z)\). Check this associative property using x = 0.1, y = 0.1, and z = 1.0 in Julia. Explain what you find.

Associative Multiplication

Do floating point numbers obey the associative rule for multiplication: \((x \times y) \times c = x \times (y \times z)\)?

Distributive Rule

Do floating point numbers obey the distibutive rule: \(a \times (x + y) = a \times x + a \times y\)?

Integral Domain

Is \(0 \times x = 0\) true for all floating point numbers \(x\)?

Existence of Multiplicative Inverse

Is \(x / a = x \times (1 / a)\) always true?

Commutativity

Addition and multiplication of real numbers obey the commutative laws \(x + y = y + x\) and \(x \times y = y \times x\), respectively. Do these laws hold for floating point numbers?

Problem 3

In class we learned about mutable and immutable types in Julia. Here we examine how these concepts interact with functions.

Experiment

Consider the following code:

# this gets called for array inputs
function set_to_one!(x::Array)
    x .= 1
    return x
end

# this gets called for numeric inputs
function set_to_one!(x::Number)
    x = 1
    return x
end

Test these methods using different inputs (Array and Number types).

You do not need to provide any solution here; just experiment on your own.

Tip
  • Use ismutable() and isimmutable() on types (not objects) to check whether a particular type is (im)mutable.
  • You might consider adding println() or @show statements to the function definitions above, letting you peek at the state of x within the function and after the function is run.
  • Remember that .= is broadcast assignment. You can edit to = or x[1] = 1 or any variation thereof.
  • Re-run the cell with method definitions for them to take effect!

Test your understanding

Based on your experiments:

  1. Can you modify a mutable object, like Array, inside a function?
  2. Can you modify an immutable object, like Char, inside a function?
